## Publish free with GitHub Pages
1. Sign in or create an account at https://github.com/
2. Create a new public repository, for example `aditya-portfolio`.
3. Upload `index.html`, `style.css`, and `script.js` from this folder to the repository root.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then save.
7. Wait a few minutes. GitHub Pages will show your public website URL, usually `https://YOUR-USERNAME.github.io/aditya-portfolio/`.
